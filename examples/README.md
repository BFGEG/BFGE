# Сценарии BFGE

Запускайте команды из корня репозитория. Для просмотра нужна графическая сессия
с поддерживаемым GPU; закройте окно, чтобы завершить сценарий.

## Общая демонстрация

Камера движется среди множества объектов и показывает основные возможности сцены:

```bash
cargo run --release --locked --example showcase
```

## Направленный свет

Два неподвижных куба и плоскость показывают изменение освещения:
направление света совершает полный оборот примерно за восемь секунд.

```bash
cargo run --release --locked --example lighting_demo
```

## Пролёт над городом

Камера облетает город из 144 разноцветных зданий, пока меняется направление света:

```bash
cargo run --release --locked --example city_flyover
```

## Вращающаяся спираль

Камера обходит спираль из 96 цветных ступеней; сама конструкция вращается:

```bash
cargo run --release --locked --example spiral_sculpture
```

## Коридор с арками

Камера пролетает через 30 цветных арок, разворачивается и летит обратно:

```bash
cargo run --release --locked --example depth_corridor
```
