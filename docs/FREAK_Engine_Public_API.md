# FREAK Engine — публичный API

## Назначение

Документ описывает методы, доступные клиентскому приложению для взаимодействия с движком. Сигнатуры даны в терминах Rust; у каждого метода есть Rustdoc-комментарий. Это спецификация интерфейса: тел методов и внутренние способы работы здесь нет.

Публичный API охватывает запуск и завершение движка, управление сценой, загрузку модели, изменение размера изображения, получение готовых изображений, а также сохранение и восстановление сцены. Клиентское приложение не управляет главным циклом движка (`EngineLoop`) напрямую.

## Типы API

Имена типов ниже используются в сигнатурах трейтов. Идентификаторы узлов и объектов являются непрозрачными для клиента: их можно получить от движка, передать обратно в методы и сравнивать, но нельзя самостоятельно создавать или изменять.

- `ImageSize` — ширина и высота требуемого изображения.
- `SceneNodeId` — идентификатор узла сцены.
- `SceneObjectId` — идентификатор загруженного объекта сцены.
- `Transform` — положение, поворот и масштаб по трём осям.
- `ViewpointState` — положение, направление взгляда и степень приближения точки обзора.
- `SceneImage` — изображение, готовое для получения клиентским приложением. В первой версии — RGBA8 (см. `FREAK_Engine_Architecture.md`, §23).
- `EngineError`, `SceneError`, `ModelLoadError`, `ScenePersistenceError` — сообщения об ошибках соответствующих операций.

## Трейт `EngineApi`

```rust
use std::path::Path;

/// Публичные операции управления движком и обмена данными с клиентом.
pub trait EngineApi {
    /// Инициализирует внутренние части движка и создаёт начальную сцену.
    ///
    /// Начальная сцена содержит корневой узел и точку обзора со значениями
    /// по умолчанию, но не содержит объектов сцены.
    fn initialize(&mut self, initial_image_size: ImageSize) -> Result<(), EngineError>;

    /// Завершает работу движка и его внутренних частей.
    fn shutdown(&mut self) -> Result<(), EngineError>;

    /// Возвращает доступ к операциям над текущей сценой.
    fn scene(&mut self) -> &mut dyn SceneApi;

    /// Загружает модель из файла и создаёт для неё отдельный объект сцены.
    ///
    /// Объект сразу связывается с указанным узлом. Каждый вызов создаёт новый
    /// объект, в том числе при повторной загрузке того же файла.
    fn load_model(
        &mut self,
        path: &Path,
        parent: SceneNodeId,
    ) -> Result<SceneObjectId, ModelLoadError>;

    /// Задаёт размер изображения, создаваемого движком.
    ///
    /// Метод можно вызывать во время работы движка.
    fn set_image_size(&mut self, size: ImageSize) -> Result<(), EngineError>;

    /// Назначает получателя изображений, готовых в главном цикле движка (`EngineLoop`).
    ///
    /// Метод можно вызвать до инициализации, чтобы получить первое изображение.
    /// Клиент не запускает отображение отдельным вызовом; движок сам вызывает
    /// получателя при готовности каждого нового изображения.
    fn set_image_listener(&mut self, listener: Box<dyn ImageListener>);

    /// Сохраняет полное состояние сцены в определённое движком место хранения.
    ///
    /// В движке хранится одна сцена; новое сохранение заменяет предыдущее.
    /// Если полное сохранение невозможно, метод возвращает ошибку и не считает
    /// частичное сохранение успешным.
    fn save_scene(&mut self) -> Result<(), ScenePersistenceError>;

    /// Восстанавливает сохранённую сцену, если текущая сцена не содержит объектов.
    ///
    /// Восстановление заменяет пустое состояние полным сохранённым состоянием.
    /// Если сохранения нет, метод завершается без ошибки и оставляет сцену пустой.
    /// Если текущая сцена занята или восстановление не удалось целиком, метод
    /// возвращает ошибку и не изменяет текущее состояние.
    fn restore_scene(&mut self) -> Result<(), ScenePersistenceError>;
}
```

## Трейт `SceneApi`

```rust
/// Операции создания и изменения пространственной сцены.
pub trait SceneApi {
    /// Возвращает корневой узел, созданный вместе со сценой.
    fn root_node(&self) -> SceneNodeId;

    /// Создаёт дочерний узел для указанного родительского узла.
    fn create_node(&mut self, parent: SceneNodeId) -> Result<SceneNodeId, SceneError>;

    /// Задаёт положение, поворот и масштаб узла относительно его родителя.
    ///
    /// Для корневого узла преобразование задаётся относительно сцены.
    fn set_node_transform(
        &mut self,
        node: SceneNodeId,
        transform: Transform,
    ) -> Result<(), SceneError>;

    /// Перепривязывает объект к другому узлу.
    ///
    /// После перепривязки положение, поворот и масштаб объекта
    /// определяются новым узлом.
    fn reparent_object(
        &mut self,
        object: SceneObjectId,
        new_parent: SceneNodeId,
    ) -> Result<(), SceneError>;

    /// Возвращает текущее состояние единственной точки обзора.
    fn viewpoint(&self) -> ViewpointState;

    /// Задаёт положение, направление взгляда и степень приближения точки обзора.
    fn set_viewpoint(&mut self, state: ViewpointState) -> Result<(), SceneError>;
}
```

## Трейт `ImageListener`

```rust
/// Получатель уведомлений о готовых изображениях сцены.
pub trait ImageListener {
    /// Вызывается движком, когда подготовлено новое изображение сцены.
    fn image_ready(&mut self, image: &SceneImage);
}
```

## Операции, отсутствующие в API первой версии

Публичный API первой версии не предоставляет методов для:

- изменения преобразования объекта сцены отдельно от его узла;
- запуска отдельного обновления или отображения кадра;
- передачи движку пользовательских систем;
- ручного создания модели или изменения её геометрии и цвета;
- создания объекта из встроенного меша вместо загрузки модели (см. `FREAK_Engine_Architecture.md`, §13.3);
- загрузки текстур или переопределения внешнего вида модели;
- скрытия или удаления узлов, объектов либо частей составной модели.

## Ошибки

- Ошибки запуска и завершения движка, а также изменения размера изображения возвращаются как `EngineError`.
- Ошибки работы с узлами, объектами и точкой обзора возвращаются как `SceneError`.
- Ошибки загрузки модели, включая неподдерживаемый или повреждённый файл, возвращаются как `ModelLoadError`.
- Ошибки сохранения и восстановления сцены возвращаются как `ScenePersistenceError`.

Формат сохранённой сцены этим документом не задаётся; в первой версии сохранение хранится в памяти движка (см. `FREAK_Engine_Architecture.md`, §18).
