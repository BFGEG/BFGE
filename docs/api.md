# Возможности API BFGE

Документ описывает доступные клиентскому приложению действия и наблюдаемое
поведение движка. Полные объявления API находятся в Rustdoc; настройка сцены,
освещения и моделей раскрыта в [руководстве пользователя](user-guide.md).

## Создание и управление движком

| Действие | Поведение |
| --- | --- |
| `Engine::new()` | Создать движок и начальное состояние сцены без открытия окна. |
| `initialize` | Открыть окно и подготовить графику. Выполнить на главном потоке с ненулевым размером окна. Заранее подготовленную сцену сохранить; повторную инициализацию активной сессии отклонить. |
| `run` | Запустить цикл кадров в инициализированной сессии. Метод блокирует текущий поток до закрытия окна или ошибки; сам по себе ресурсы не освобождает. |
| `set_window_size` | Задать ненулевой размер активного окна, когда цикл не выполняется. Изменение размера окна во время цикла обрабатывается автоматически. |
| `shutdown` | Завершить активную сессию и сбросить её сцену и модели. Снимок и обработчики кадров остаются в экземпляре движка. |

Движок создаёт сцену с корневым узлом, перспективной точкой обзора и настройками
освещения по умолчанию. Сцену можно подготовить до открытия окна. После завершения
сессии доступно создание новой сцены или восстановление сохранённой.

## Действия со сценой

| Действие | Поведение |
| --- | --- |
| `scene` | Получить доступ к текущему содержимому сцены. |
| `root_node` | Получить корневой узел и начать от него построение иерархии. |
| `create_node` | Добавить дочерний узел с исходным преобразованием без сдвига, поворота или масштаба. |
| `set_node_transform` | Заменить положение, поворот и масштаб узла. Дочерние узлы и объекты наследуют его итоговое преобразование. |
| `clone_object` | Создать новый экземпляр существующего объекта под выбранным узлом. Экземпляры используют общую геометрию, без повторной загрузки модели. |
| `remove_object` | Удалить объект из сцены. Его узел, геометрия и остальные экземпляры сохраняются. Удалённый ID становится недействительным. |
| `reparent_object` | Переместить объект под другой узел. Объект принимает положение, поворот и масштаб нового родителя. |
| `viewpoint` | Получить положение, направление взгляда и угол обзора текущей точки обзора. |
| `set_viewpoint` | Задать положение, направление взгляда и угол перспективного обзора. Точка обзора не входит в иерархию узлов. |
| `lighting` | Получить действующие настройки фонового и направленного света. |
| `set_lighting` | Задать общий фоновый свет и направленный источник. При некорректных значениях сохранить прежние настройки. |

Требования к численным значениям преобразований и точки обзора приведены в
[руководстве](user-guide.md#точка-обзора).

## Обработчики и порядок кадра

| Действие | Поведение |
| --- | --- |
| `add_event` | Зарегистрировать действия начала и конца кадра. Вызывать их в порядке регистрации; разрешить им изменять сцену. |

Обработчик получает `&mut FrameContext` и `&EventTime`, возвращает
`Result<(), EngineError>`. Через `context.scene()` доступны операции сцены,
через `context.load_model(path, parent)` — загрузка новой модели во время `run()`.
Загрузка синхронная: чтение и разбор файла задерживают текущий кадр. Ошибка
загрузки передаётся из `run()` как `EngineError::ModelLoad`, ошибка сцены — как
`EngineError::Scene`; в обработчике для обоих типов можно использовать `?`.

Один цикл кадра выполняется в таком порядке:

1. Обработать события окна. При закрытии завершить цикл; изменение размера учесть до подготовки кадра.
2. Вызвать обработчики начала кадра. Их изменения попадут в текущий кадр.
3. Подготовить сцену и выполнить попытку отображения.
4. Вызвать обработчики конца кадра. Их изменения будут видны со следующего кадра.

Ошибка обработчика завершает цикл, но не отменяет уже внесённые изменения сцены.
Временный пропуск изображения из-за состояния поверхности не считается ошибкой
отображения. При нулевом размере окна кадры и обработчики приостанавливаются.
Обработчики нельзя удалить после регистрации.

Обработчикам доступны интервалы времени между кадрами и между вызовами
обработчиков. Первый интервал отсчитывается от запуска цикла; время свёрнутого
окна включается в интервал после восстановления.

## Загрузка моделей

| Действие | Поведение |
| --- | --- |
| `load_model` | Загрузить модель из OBJ, glTF 2.0 или GLB и создать для неё отдельный объект сцены под выбранным узлом. Доступна до открытия окна и во время работы через контекст кадра; повторная загрузка файла создаёт ещё один объект и ресурс. |

Загружается статическая треугольная геометрия. Все части модели следуют одному
объекту и используют общий цвет. При ошибке чтения или проверки сцена остаётся
без изменений. Поддерживаемые данные описаны в разделе
[загрузки моделей](user-guide.md#загрузка-моделей).

## Сохранение и восстановление

| Действие | Поведение |
| --- | --- |
| `save_scene` | Сохранить в памяти движка иерархию, объекты, данные моделей, точку обзора и освещение. Новый снимок заменяет предыдущий. |
| `restore_scene` | Заменить пустую сцену сохранённым снимком. Если снимка нет, оставить пустую сцену без изменений. |

Восстановление выполнять в следующем порядке:

1. Проверить отсутствие объектов в текущей сцене.
2. Если снимок отсутствует, оставить пустую сцену без изменений.
3. Проверить сохранённое состояние и заменить им сцену.

При наличии объектов вернуть ошибку без изменений. При ошибке проверки снимка
сохранить текущее состояние. Созданные вручную узлы не мешают восстановлению:
они заменяются вместе с остальным содержимым.
Снимок хранится только в памяти экземпляра движка, переживает завершение
оконной сессии и теряется при уничтожении движка. Запись снимка в файл не
предусмотрена.
