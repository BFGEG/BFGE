# Модули BFGE

Документ служит картой исходного кода: для каждой части указаны её зона
ответственности и место в работе движка. Общие связи между частями показаны в
[архитектурном обзоре](architecture.md); действия клиентского приложения — в
[обзоре API](api.md).

## Библиотека движка

| Модуль | Ответственность |
| --- | --- |
| `core` | Центральное управление движком. Фасад связывает публичные операции с подсистемами, а цикл кадров обрабатывает события окна, вызывает клиентские обработчики и запускает обновление сцены и отображение. Здесь же определены ошибки уровня движка. |
| `platform` | Владеет окном на время сессии и передаёт движку его события и актуальный размер. Оконные операции выполняются на главном потоке. |
| `scene` | Хранит дерево узлов и привязанные к нему объекты, а также точку обзора и общее освещение. Предоставляет операции изменения сцены и проверяет связи между её сущностями. |
| `resources` | Хранит геометрию моделей отдельно от объектов сцены. Объекты ссылаются на ресурсы, поэтому одна геометрия может использоваться несколькими объектами. Модуль также предоставляет встроенную геометрию. |
| `systems` | Содержит операции жизненного цикла, загрузку моделей и снимки сцены. Загрузчик преобразует данные файлов в ресурсы и объекты; сохранение копирует состояние сцены в память движка. |
| `render` | Формирует данные кадра из состояния сцены и передаёт их графической системе через отдельную границу взаимодействия. Здесь также находятся владелец графической системы и статистика прохода. |
| `backend/wgpu` | Реализует графическую систему: управляет поверхностью окна, графическим конвейером, буферами мешей и глубины, отправляет команды отрисовки и представляет готовый кадр. |

## Вспомогательные части репозитория

| Расположение | Назначение |
| --- | --- |
| `benchmark` | Отдельный измерительный инструмент, профили нагрузки и описание экспериментов. Собирается при включённой функции `stress-benchmark`. |
| `examples` | Самостоятельные приложения, демонстрирующие настройку сцены и использование движка. Краткое описание и команды запуска находятся в [списке примеров](../examples/README.md). |
| `tests` | Интеграционные проверки публичного поведения и импорта моделей. Графические проверки требуют оконную сессию и графический адаптер. |

## Направление взаимодействия

1. Клиент обращается к фасаду движка и настраивает сцену.
2. Системы загружают модели в ресурсы и связывают их с объектами сцены.
3. Цикл кадров вызывает обработчики клиента и запрашивает подготовку кадра.
4. Модуль отображения собирает данные сцены и передаёт их графическому backend.
5. Backend отправляет команды графическому устройству и показывает кадр в окне.

Профили, запуск и результаты измерений собраны в [разделе бенчмарков](../benchmark/README.md).
